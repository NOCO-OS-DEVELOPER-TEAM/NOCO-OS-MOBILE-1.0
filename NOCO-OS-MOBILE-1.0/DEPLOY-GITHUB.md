# NOCO OS Mobile 1.0 auf GitHub Pages

## Dateien
Lade den kompletten Inhalt dieses Ordners in ein GitHub-Repository:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`
- `icon.svg`
- `.nojekyll`

## GitHub Pages aktivieren
1. Auf GitHub ein neues Repository erstellen, zum Beispiel `noco-os-mobile`.
2. Alle Dateien aus diesem Ordner hochladen.
3. In GitHub auf `Settings` gehen.
4. Links auf `Pages` gehen.
5. Bei `Source` die Option `Deploy from a branch` nehmen.
6. Branch `main` und Ordner `/(root)` auswählen.
7. Speichern.

Nach kurzer Zeit ist die App unter dieser Adresse online:

`https://DEIN-NAME.github.io/REPO-NAME/`

Beispiel:

`https://noah.github.io/noco-os-mobile/`

## Auf dem iPhone als App installieren
1. Den GitHub-Pages-Link auf dem iPhone in `Safari` öffnen.
2. Unten auf den Teilen-Button drücken.
3. `Zum Home-Bildschirm` auswählen.
4. Name prüfen, zum Beispiel `NOCO Mobile`.
5. `Hinzufügen` drücken.

Danach startet NOCO OS Mobile wie eine App im Vollbild.

## Wichtig bei Updates
Wenn du Dateien änderst und wieder hochlädst:

1. In GitHub committen.
2. Auf dem iPhone die App einmal komplett schließen.
3. Safari öffnen und die Seite neu laden.
4. Wenn noch alte Dateien kommen, kurz warten oder den Home-Bildschirm-Link löschen und neu hinzufügen.
